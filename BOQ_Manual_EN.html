1 · Introduction

The BOQ Tool is a standalone browser-based Bill of Quantities tool built for BOQ Tool PICs. Use it to build a room-by-room list of furniture items — kitchen cabinets, wardrobes, and accessories — with showroom pricing, then export to Excel or PDF for client presentation and send to Head Office / Pricing Dept for final price verification.

No installation needed. Open BOQ_Tool.html in any modern browser (Chrome, Edge, or Firefox recommended). The entire tool — including the full price database — runs inside that single file.

All prices shown are Showroom Prices (excl. PPN). Sales pricing and discounting are handled separately by the Sales team.

2 · Interface Overview

The tool is divided into four main zones:

Topbar

Brand mark, project breadcrumb, the alternative/version chip, the tool version and price list version pills (top right), and load/save/export action buttons.

Sidebar

Unit list (rooms/locations) and navigation to Overview and Totals. It stays pinned in place as the main area scrolls, and can be resized by dragging its right edge or collapsed to an icon rail.

Main Area

The working area. Switches between Overview, Totals Matrix, and Unit editing views depending on what you click.

Toast Notifications

Brief confirmations and warnings appear in the bottom-right corner and fade automatically.

3 · Starting a New Project

  1. Open the tool — it starts with one default unit called "Kitchen" and an empty project.
  2. In the Overview view, fill in: Project Name, Client, PIC, and Notes to Head Office / Pricing Dept (Price List sits narrow on the right). There is no project-wide date field — the quotation date lives on each saved version instead (see Chapter 8).
  3. Check the Price List dropdown — it defaults to the latest version. Leave it as-is for new projects.
  4. Rename the default unit by clicking its name in the sidebar and typing a new name (e.g. "Master Bedroom"). Add more units with the + Add Unit button in Overview.
Unit = Room or Location. Create one unit per room (e.g. Master Bedroom, Kitchen, Living Room). Each unit gets its own tab in the export.

4 · Adding Items

Click a unit name in the sidebar to open its editing view. You'll see three tabs at the top: Kitchen, Wardrobe, and Accessories. Each tab has an add bar at the top and a table of added items below.

4.1 Kitchen

  1. Select a Category (Base Unit, Wall Unit, Tall Unit, etc.).
  2. Select a Finish from the dropdown. The Thickness badge fills in automatically when known, or shows — if no thickness data exists for that finish.
  3. Select Handle: Standard or Gola.
  4. Click the Search / Browse field and start typing, or click to see all items for the current category and finish. You can search by description, category, size, or note — matching text is highlighted. Click an item to select it, or press Enter to pick the top match. The price preview updates on the right.
  5. Set Qty (whole numbers or decimals to two places, e.g. 1.23). Qty 0 is allowed — use it for a line you want listed but not yet costed. The tool warns you, marks the row with an amber QTY 0 tag, and the row counts Rp 0 in every total. Press Enter — in either the search field or the qty field — to add the item instantly, or click + Add. After adding, the search clears and refocuses so you can type the next item straight away.
⚠ Gola validation: Gola handle is only supported for certain item + finish combinations. If you select Gola for an unsupported item, the tool will block the add and show an error. Switch to Standard or choose a different finish.

4.2 Wardrobe

Same flow, but the filter controls adapt to the selected category:

4.3 Accessories

Select a Category (Solid Surface, Lighting, Handles, etc.), search or browse for an item, set qty, and click + Add. No finish selection is needed for accessories.

4.4 Custom Items

Click the Custom button on any tab to add an item that isn't in the price database. Fill in the description, finish or material, thickness (optional, free text), unit price (IDR), qty, unit type, and optional notes. Custom items appear with a CUSTOM badge in the table.

5 · Managing the Table

Once items are added, you can edit, reorder, or remove them directly in the table.

Add a noteClick the Notes field on the row and type (e.g. "custom size", "check stock").

Delete a rowClick the × icon at the far right of the row.
Reorder rowsDrag the dot-grid handle on the far left of the row up or down.

Units can also be reordered by dragging the dot-grid handle next to their name in the sidebar.

Item Groups

Groups let you bundle related rows into a named package — for example a "Kitchen Island" made of base units, a solid-surface top, and handles. A group can span all three sections (Kitchen + Wardrobe + Accessories), and each unit has its own groups. Grouping is optional — items you don't group simply stay as loose rows.

  1. Create a group: select some rows, then click + Group in the selection bar → New group…, and give it a name.
  2. Add more to it: select more rows (on any tab) and click + Group → pick the existing group. Because groups can span sections, you build a cross-section package tab by tab.
  3. Remove from a group: select the rows and click - Group.

Grouped rows appear under a group band showing the group name, its item count, and its combined total (across all sections). On the band you can collapse it (chevron), rename it (double-click the name or the pencil), or remove the group (the items are kept, just ungrouped). Any rows you haven't grouped gather under an Other items band.

Groups flow into the exports. The PDF and Excel are laid out group-first — each group is its own band with a subtotal, and a small section tag (KITCHEN / WARDROBE / ACCESSORIES) on each row shows where it came from. A unit with no groups just lists its items flat.

6 · Overview & Totals

Overview

Click Overview in the sidebar at any time to return to the project summary. Here you can:

  • Edit all project information fields
  • See stat cards: total units, total items, the alternative & version you're working on, and grand total
  • Use the Revisions & Alternatives panel to save quotable versions and offer the client side-by-side alternatives (see Chapter 8)
  • See the Units Overview table — Kitchen / Wardrobe / Accessories subtotals per unit
  • Click any unit name to jump directly to that unit's editing view
  • Save, export to Excel, or save to PDF

Totals Matrix

Click Totals in the sidebar for a full cross-breakdown: every unit as a row, every section (Kitchen / Wardrobe / Accessories) as a column, with a grand total row at the bottom. Useful for a quick final review before exporting.

7 · Price List Versions

The Price List dropdown in Project Information shows which version of the SM price list is being used for this project.

  • New projects always default to the latest version embedded in the tool.
  • When you load an older project (saved with a previous price list), an amber ⚠ newer version available chip appears next to the dropdown.
  • Switching versions re-prices all non-custom items silently against the selected version's data. You can switch back at any time.
When to switch: Only switch to a newer price list once you're ready to present updated pricing to the client. Switching updates all item prices — compare the new grand total before sending.

8 · Saving & Loading

Saving

Click Save .boq in the Overview header. The browser saves a file named {Project Name}_{Date}.boq (e.g. Pak Budi_Kebayoran Baru_13-07-2026.boq, dates shown day-month-year). This saves the whole project to one file on your computer — every unit, item, and all your saved versions & alternatives.

Crash protection: the tool auto-saves your working state into the browser's local storage (on this computer, in this browser — not a file) a few seconds after every edit, and warns you before closing the tab. If the browser ever closes unexpectedly, reopen the tool — it will offer to restore your unsaved work. This is a safety net, not a replacement for saving your .boq file.

Loading

Click Load .boq in the Overview header. Select a .boq file. The tool restores the full project: all units, items, quantities, notes, and the price list version stored at save time.

Faster: drag and drop. Drag a .boq file from Windows Explorer onto any part of the tool — a "Drop to open" panel appears over the page, and releasing the file loads it. No need to find the Load button or navigate the file dialog. If the project you have open still has changes that were never saved to a .boq file, the tool asks before replacing it, so a stray drag can't lose your work. Dropping anything that isn't a .boq is simply refused.

The .boq file is plain text (JSON) — safe to email, archive, or back up. Head Office / Pricing Dept will eventually manage revision history through the CRM system.

Revisions & Alternatives

The Revisions & Alternatives panel (in Overview) is how you save quotable snapshots of your work — this is separate from saving a .boq file to disk.

  • Save as v1, v2, … — commit the current calculation as a numbered version. While a version is still a Draft, saving updates it in place; once you mark it Ready for quotation, the next save creates the next version and marks older ones Superseded.
  • Alternatives (Alt A, Alt B, …) — offer the client different schemes side by side (e.g. two finish or layout options). Each alternative keeps its own version history.
  • Each version has its own date. When you save a version it is dated today; the date is shown next to the v# chip (with a dashed underline). Click it to change that version's date — so v1 can read an earlier date than v2. This date is what prints on that version's exported document. Dates are shown day-month-year (e.g. 13-07-2026).
  • The Revisions & Alternatives panel and the Working On card show which Alt · version you're editing; the topbar chip shows the live autosave status. All of it travels inside the .boq file.
Exporting a draft? If you export the working copy before saving a version, the document is dated today. To put a specific date on a quotation, save it as a version and set that version's date.

9 · Exporting

Project Name and Client are required before any export. If either is empty, the tool jumps to Overview and highlights the missing field in red.

Choosing what to export

As soon as the project has saved versions or more than one alternative, the export popup starts with a "What to export" picker: one row per alternative, each with a checkbox and a version dropdown. By default your current alternative is ticked with its latest content selected (the working copy if you have unsaved edits, otherwise the latest saved version). You can switch any row to an earlier version, tick extra alternatives, or use Select all. Everything you tick goes into one document: the PDF gets a titled divider per alternative (each starting on its own page) with its own grand total, and Excel gets a Summary and unit sheets per alternative (Summary A, A · Kitchen 1, …).

The buffer question

If your BOQ contains buffer items (insurance stock, marked with the shield), every export first asks which document you want:

  • With buffer — for Quotation: all items included. Buffer rows are marked (blue-tinted in the PDF and in Excel, with a Buffer column) and totals are shown both including and excluding buffer. The file is named …_BOQ(Buffer).
  • Without buffer — for Sales Order: for ordering to Head Office / Pricing Dept. Buffer items are left out of the list and totals entirely. The file is named …_BOQ.

If the BOQ has no buffer items, the question is skipped and the export runs directly.

Export to Excel EXCEL

Click Export Excel in the Overview header. The tool generates a styled .xlsx file in the branded document format — the BOQ Tool and MULYA logos at the top of every sheet, a project detail band, minimal ink-and-brass styling, blue-tinted buffer rows, and Rp number formats — with one sheet per unit plus a Summary sheet (unit totals and the full item list). Items are laid out group-first: each group is a band with its own subtotal, followed by an Other items band; a unit with no groups just lists its items flat. File name: {Project Name}_{Date}_BOQ(Buffer).xlsx (day-month-year) — the alternative/version is stated inside the document, not in the filename. Excel export works fully offline — no internet needed.

Save to PDF

Click Save PDF in the Overview header. The export popup lets you choose the page format — A4 Portrait (two-line items, compact notes) or A4 Landscape (one-line items, wide notes column). The tool generates the PDF itself and saves it directly — no print dialog, no printer settings, works offline. The document follows the branded BOQ format: BOQ Tool logo top-left, MULYA logo top-right, project detail band (with the exported version's date), one unit per section with elegant serif titles, group-first bands (group name + subtotal, a small KITCHEN / WARDROBE / ACCESSORIES tag per row, and an Other items band for anything ungrouped), blue-tinted buffer rows with a BUFFER tag (in the with-buffer version), grand total block, and page numbers. Filename: {Project Name}_{Date}_BOQ(Buffer).pdf.

Choosing where files are saved

When the tool is opened by double-clicking the HTML file, the browser saves exports straight to your Downloads folder (browsers do not allow a location dialog for double-clicked pages). To be asked for a folder on every export, turn on this one-time browser setting: Chrome → Settings → Downloads → "Ask where to save each file before downloading". After that, every PDF, Excel, and .boq save opens the normal Windows Save As dialog.

10 · Tips & Tricks

Clone a Unit to Compare Finishes

A fast way to show a client the same room priced in two different finishes side by side:

  1. Build one unit completely with Finish A (e.g. TZ High Gloss).
  2. In the sidebar, click the clone icon (copy symbol) next to the unit name. An exact duplicate is created.
  3. Open the cloned unit and go to the Kitchen or Wardrobe tab.
  4. Tick the header checkbox to select all rows.
  5. In the selection bar above the table, click Change Finish.
  6. Select Finish B (e.g. Classic Doors PVC) and click Apply.

Both units now appear in the Totals Matrix and in the exported PDF — the client can compare the grand totals for each finish option at a glance.

Items where Finish B is not available keep their original finish and are counted as "skipped" in the confirmation toast.

Other Useful Tips

SituationWhat to do
Partial quantities Type decimals directly into the qty field (e.g. 1.23 for 1.23 sets of solid surface). Values are stored to 2 decimal places.
Per-item instructions Use the Notes column for special instructions that should appear on the export (e.g. "custom size", "check availability with Head Office / Pricing Dept").
Bundle a package Use Item Groups (Chapter 5) to gather the pieces of one package — e.g. an island's cabinets, top, and handles — under a named band with its own subtotal, even across Kitchen / Wardrobe / Accessories.
Track which version you sent The Working On card in Overview shows the Alt · version you're on. Mark a version Ready for quotation before sending to Head Office / Pricing Dept, and note the Alt/version label so you can match it if there are questions.
Item not in database Use the Custom button. Custom items are excluded from price list version switching — their prices stay exactly as you entered them.
Reorder rooms Drag units up or down in the sidebar using the dot-grid handle. The new order is reflected in the Excel export and PDF.
