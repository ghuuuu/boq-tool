1 · Introduction

The SM BOQ Tool is a standalone browser-based Bill of Quantities tool built for Stella Mobili PICs. Use it to build a room-by-room list of furniture items — kitchen cabinets, wardrobes, and accessories — with showroom pricing, then export to Excel or PDF for client presentation and send to SM Jakarta for final price verification.

No installation needed. Open StellaMobili_BOM_Tool.html in any modern browser (Chrome, Edge, or Firefox recommended). The entire tool — including the full price database — runs inside that single file.

All prices shown are Showroom Prices (excl. PPN). Sales pricing and discounting are handled separately by the Sales team.

2 · Interface Overview

The tool is divided into four main zones:

Topbar

Brand mark, project breadcrumb, the alternative/version chip, the tool version and price list version pills (top right), and load/save/export action buttons.

Sidebar

Unit list (rooms/locations), navigation to Overview and Totals, View Database and Import Price List buttons at the bottom.

Main Area

The working area. Switches between Overview, Totals Matrix, and Unit editing views depending on what you click.

Toast Notifications

Brief confirmations and warnings appear in the bottom-right corner and fade automatically.

3 · Starting a New Project

  1. Open the tool — it starts with one default unit called "Kitchen" and an empty project.
  2. In the Overview view, fill in: Project Name, Client, PIC, Date, and Notes to SM Jakarta.
  3. Check the Price List dropdown — it defaults to the latest version. Leave it as-is for new projects.
  4. Rename the default unit by clicking its name in the sidebar and typing a new name (e.g. "Master Bedroom"). Add more units with the + Add Unit button in Overview.
Unit = Room or Location. Create one unit per room (e.g. Master Bedroom, Kitchen, Living Room). Each unit gets its own tab in the export.

4 · Adding Items

Click a unit name in the sidebar to open its editing view. You'll see three tabs at the top: Kitchen, Wardrobe, and Accessories. Each tab has an add bar at the top and a table of added items below.

4.1 Kitchen

  1. Select a Category (Base Unit, Wall Unit, Tall Unit, etc.).
  2. Select a Finish from the dropdown. The Thickness badge fills in automatically when known, or shows — if no thickness data exists for that finish.
  3. Select Handle: Standard or Gola.
  4. Click the Search / Browse field and start typing, or click to see all items for the current category and finish. You can search by description, category, size, or note — matching text is highlighted. Click an item to select it, or press Enter to pick the top match. The price preview updates on the right.
  5. Set Qty (whole numbers or decimals to one place, e.g. 1.5). Press Enter — in either the search field or the qty field — to add the item instantly, or click + Add. After adding, the search clears and refocuses so you can type the next item straight away.
⚠ Gola validation: Gola handle is only supported for certain item + finish combinations. If you select Gola for an unsupported item, the tool will block the add and show an error. Switch to Standard or choose a different finish.

4.2 Wardrobe

Same flow, but the filter controls adapt to the selected category:

4.3 Accessories

Select a Category (Solid Surface, Lighting, Handles, etc.), search or browse for an item, set qty, and click + Add. No finish selection is needed for accessories.

4.4 Custom Items

Click the Custom button on any tab to add an item that isn't in the price database. Fill in the description, finish or material, thickness (optional, free text), unit price (IDR), qty, unit type, and optional notes. Custom items appear with a CUSTOM badge in the table.

Once items are added, you can edit, reorder, or remove them directly in the table.

6 · Overview & Totals

Overview

Click Overview in the sidebar at any time to return to the project summary. Here you can:

  • Edit all project information fields
  • See stat cards: total units, total items, the alternative & version you're working on, and grand total
  • Use the Revisions & Alternatives panel to save quotable versions and offer the client side-by-side alternatives (see Chapter 8)
  • See the Units Overview table — Kitchen / Wardrobe / Accessories subtotals per unit
  • Click any unit name to jump directly to that unit's editing view
  • Save, export to Excel, or save to PDF

Totals Matrix

Click Totals in the sidebar for a full cross-breakdown: every unit as a row, every section (Kitchen / Wardrobe / Accessories) as a column, with a grand total row at the bottom. Useful for a quick final review before exporting.

7 · Price List Versions

The Price List dropdown in Project Information shows which version of the SM price list is being used for this project.

  • New projects always default to the latest version embedded in the tool.
  • When you load an older project (saved with a previous price list), an amber ⚠ newer version available chip appears next to the dropdown.
  • Switching versions re-prices all non-custom items silently against the selected version's data. You can switch back at any time.
When to switch: Only switch to a newer price list once you're ready to present updated pricing to the client. Switching updates all item prices — compare the new grand total before sending.

8 · Saving & Loading

Saving

Click Save .smbq in the Overview header. The browser downloads a file named {Project Name}_{Date}_Alt-{A}.smbq (e.g. Pak Budi_Kebayoran Baru_2026-07-11_Alt-A.smbq; a committed version adds -v2 etc.). This saves the whole project to one file on your computer — every unit, item, and all your saved versions & alternatives.

Crash protection: the tool auto-saves your working state into the browser's local storage (on this computer, in this browser — not a file) a few seconds after every edit, and warns you before closing the tab. If the browser ever closes unexpectedly, reopen the tool — it will offer to restore your unsaved work. This is a safety net, not a replacement for saving your .smbq file.

Loading

Click Load .smbq in the Overview header. Select a .smbq file. The tool restores the full project: all units, items, quantities, notes, and the price list version stored at save time.

The .smbq file is plain text (JSON) — safe to email, archive, or back up. SM Jakarta will eventually manage revision history through the CRM system.

Revisions & Alternatives

The Revisions & Alternatives panel (in Overview) is how you save quotable snapshots of your work — this is separate from saving a .smbq file to disk.

  • Save as v1, v2, … — commit the current calculation as a numbered version. While a version is still a Draft, saving updates it in place; once you mark it Ready for quotation, the next save creates the next version and marks older ones Superseded.
  • Alternatives (Alt A, Alt B, …) — offer the client different schemes side by side (e.g. two finish or layout options). Each alternative keeps its own version history.
  • The Revisions & Alternatives panel and the Working On card show which Alt · version you're editing; the topbar chip shows the live autosave status. All of it travels inside the .smbq file.

9 · Exporting

Project Name and Client are required before any export. If either is empty, the tool jumps to Overview and highlights the missing field in red.

The buffer question

If your BOQ contains buffer items (insurance stock, marked with the shield), every export first asks which document you want:

  • With buffer — for Quotation: all items included. Buffer rows are marked (blue-tinted in the PDF and in Excel, with a Buffer column) and totals are shown both including and excluding buffer. The file is named …_BOQ(Buffer).
  • Without buffer — for Sales Order: for ordering to SM Jakarta. Buffer items are left out of the list and totals entirely. The file is named …_BOQ.

If the BOQ has no buffer items, the question is skipped and the export runs directly.

Export to Excel EXCEL

Click Export Excel in the Overview header. The tool generates a styled .xlsx file — colored headers, section bands, blue-tinted buffer rows, and Rp number formats — with one sheet per unit plus a Summary sheet (project info, unit totals, and the full item list). File name: {Project Name}_{Date}_Alt-{A}_BOQ(Buffer).xlsx. Excel export works fully offline — no internet needed.

Save to PDF

Click Save PDF in the Overview header. The tool generates the PDF itself and downloads it directly — no print dialog, no printer settings, works offline. The document is A4 portrait with the MULYA letterhead, full project details (project, client, PIC, date, version, price list, notes), one table per unit, blue-tinted buffer rows (in the with-buffer version), grand totals, and page numbers. Filename: {Project Name}_{Date}_Alt-{A}_BOQ(Buffer).pdf.

10 · Tips & Tricks

Clone a Unit to Compare Finishes

A fast way to show a client the same room priced in two different finishes side by side:

  1. Build one unit completely with Finish A (e.g. TZ High Gloss).
  2. In the sidebar, click the clone icon (copy symbol) next to the unit name. An exact duplicate is created.
  3. Open the cloned unit and go to the Kitchen or Wardrobe tab.
  4. Tick the header checkbox to select all rows.
  5. In the blue action bar that appears, click Change Finish.
  6. Select Finish B (e.g. Classic Doors PVC) and click Apply.

Both units now appear in the Totals Matrix and in the exported PDF — the client can compare the grand totals for each finish option at a glance.

Items where Finish B is not available keep their original finish and are counted as "skipped" in the confirmation toast.

Other Useful Tips

SituationWhat to do
Partial quantities Type decimals directly into the qty field (e.g. 1.5 for 1.5 sets of solid surface). Values are stored to 1 decimal place.
Per-item instructions Use the Notes column for special instructions that should appear on the export (e.g. "custom size", "check availability with SM Jakarta").
Check what's in the database Click View Database in the sidebar before adding items. Browse by section and category, then click any item to see all available finishes and prices.
Track which version you sent The Working On card in Overview shows the Alt · version you're on. Mark a version Ready for quotation before sending to SM Jakarta, and note the Alt/version label so you can match it if there are questions.
Item not in database Use the Custom button. Custom items are excluded from price list version switching — their prices stay exactly as you entered them.
Reorder rooms Drag units up or down in the sidebar using the dot-grid handle. The new order is reflected in the Excel export and PDF.
