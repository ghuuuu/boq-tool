# CLAUDE.md — BOQ Tool Developer Guide

> Read this before modifying the codebase.

---

## Architecture Overview

**BOQ Tool** is a self-contained, single-file offline web application built with vanilla JavaScript, modern CSS custom properties, and vendored export engines (ExcelJS and pdfmake).

- **Build Output**: `BOQ_Tool.html` (~3.8 MB). **Do not edit directly**; it is a build artifact generated by `src/build_tool.py`.
- **Source of Truth**: `src/BOQ_Tool_Ref.html` (markup, application JS, and custom styling).
- **Whitelabel Tokens**: `src/brand.config.json` (defines typography palette, brand name, file extension, and document prefix).
- **Offline Engines**:
  - `src/vendor/exceljs.min.js`: Excel workbook generator with cell styling and formula support.
  - `src/vendor/pdfmake.min.js` + `vfs_fonts.js`: Offline PDF generator with Libre Franklin and Libre Caslon typography.
- **Shared Chrome (`src/kit/`)**: Vendored UI frame, state machine for revisions/alternatives, autosave loop, and export layout.

---

## Build Pipeline

When `python src/build_tool.py` executes:

1. Reads `src/brand.config.json` and synthesizes CSS custom properties in `:root`.
2. Inspects `price-data/price_lists/` for any versioned catalogue JSON files (`*_v*.json`). If none exist (default 0 database mode), sets empty catalog constants `ALL_PRICE_DATA = {}`, `PRICE_LIST_VERSIONS = []`, and `PRICE_LIST_LATEST = ""`.
3. Inlines `src/vendor/exceljs.min.js` into `/*__EXCELJS_INJECTION__*/`.
4. Inlines `src/vendor/pdfmake.min.js`, `vfs_fonts.js`, and embedded Libre TTF fonts into `/*__PDFMAKE_INJECTION__*/`.
5. Encodes vector SVG and raster PNG logos into base64 and inlines into `/*__BRAND_ASSETS_INJECTION__*/`.
6. Embeds `src/kit/` (Hanken Grotesk WOFF2 screen font, `kit.css`, `kit.js`, `kit-export.js`, `bridge.js`) into `<!--__KIT_INJECTION__-->`.
7. Emits the final `BOQ_Tool.html`.

## Development Workflow

### Modifying UI or Logic
- Edit `src/BOQ_Tool_Ref.html`.
- Run `python src/build_tool.py`.
- Run `python src/check_html.py` to confirm all markers and assertions pass.

### Customizing Brand & Whitelabeling
- Update `src/brand.config.json` (change palette, brand names, file extension).
- Update logos in `src/assets/boq-logo.svg` and `src/assets/boq-logo.png`.
- Rebuild: `python src/build_tool.py`.

### Updating the Shared Kit
- If maintaining across multiple tools, update `src/kit/` or sync via `python src/sync_kit.py`.
